# ADR 0002：默认供应商改为智谱免费模型

- 状态：**已采纳，待项目负责人复核**（AI 起草并执行）
- 日期：2026-10-02

## 背景

ADR 0001 选了 DeepSeek，但落地时发现：DeepSeek 官方**没有免费额度**，必须充值（最低档约 10 元）才能调用。项目负责人是学生，希望零成本把项目跑起来并部署上线。

同时项目已经有了一个约束：AI 调用全部收在 `lib/api/ai.ts` 一处，走 OpenAI 兼容格式。这让「换供应商」变成一件只改配置的事。

## 选项

| 方案 | 免费情况 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **智谱 GLM-4.7-Flash** | 官方标注免费，无信用卡 | 国内直连、OpenAI 兼容、200K 上下文、手机号注册 | 并发上限 30 |
| 硅基流动 | 9B 以下小模型永久免费 | 模型多、延迟低 | 小模型做英语陪练质量一般 |
| 阿里云百炼 | 每模型 100 万 Token / 90 天 | 模型最全 | 有效期到期后就没了，不适合长期演示 |
| 火山引擎（豆包） | 每天 200 万 Token | 额度高 | 需在控制台手动开通模型，配置步骤多 |
| Google Gemini | 免费额度大 | 模型强 | **国内需代理**，Vercel 部署环境连不上 |
| DeepSeek 充值 10 元 | 无免费 | 质量稳定 | 要花钱，且余额用完就停 |

## 结论

默认供应商改为**智谱（`zhipu`）**，默认模型 **GLM-4.7-Flash**。

1. 完全免费 + 国内直连，学生项目能长期在线，不会因为余额归零而下线
2. OpenAI 兼容，本项目零改造成本
3. GLM-4.7-Flash 的通用对话能力足够支撑英语陪练与纠错两个场景

同时把 AI 客户端重命名为厂商中立的 `lib/api/ai.ts`，并引入 `AI_PROVIDER` 预设机制：

- `AI_PROVIDER=zhipu`（默认）→ 智谱免费模型
- `AI_PROVIDER=deepseek` → DeepSeek
- 留空 + 自定义 `AI_BASE_URL` / `AI_MODEL` → 任意 OpenAI 兼容服务

## 影响

- 环境变量从 `DEEPSEEK_*` 迁移到 `AI_*`；**旧变量名保留兼容**，不会一升级就崩
- 默认值选免费方案意味着：克隆仓库的人只要有密钥就能立刻跑通（仍需自己注册一个）
- 并发 30 的上限对个人项目无影响；将来若要做公开多人访问，需要重新评估或加缓存
- 提示词不变，模型切换后需实测一下纠错接口的 JSON Lines 输出是否稳定
